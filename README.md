# max-clipping

Skill для Claude Code під інтерв'ю клієнта Max (коуч зі схуднення).
Двофазний: спершу відбирає кліпи з транскрипту, після узгодження — ріже відео.

## Чим відрізняється від базового `clipping`

Базовий скіл ріже по таймкодах з транскрипту. Цей — **по словах**.

Whisper робить пословний транскрипт відео (таймкод на кожне слово), цитата з
плану знаходиться в ньому через difflib, і різ стає рівно на початок першого
слова та кінець останнього. Таймкоди з транскрипту при цьому лише задають
вікно пошуку, а не місце різу.

На тесті фрагменти зі зсувом таймкоду **+26 с**, **−31 с** і **+45 с** знайшлись
правильно — збіг 100 %, 100 % і 92 %.

## Дві фази

| фаза | вхід | вихід | коли |
|---|---|---|---|
| 1 — відбір | транскрипт з таймкодами | `clips_plan.md` + `clips_plan.json` | одразу як кинули транскрипт |
| 2 — нарізка | відео + узгоджений план | сирі mp4 + звіт перевірки | тільки після «ріж» |

Між фазами обов'язкова пауза на узгодження. Відео на фазі 1 не потрібне.

## Перевірка по словах — двічі

| скрипт | коли | що ловить |
|---|---|---|
| `validate_plan.py` | фаза 1, до відео | цитата справді є в транскрипті, а не переказана |
| `verify_clips.py` | фаза 2, після нарізки | перетранскрибовує готові файли і звіряє з планом |

`verify_clips.py` розрізняє три різні речі через opcodes difflib:

- `delete` — слова були в плані, у файлі їх нема → різ з'їв, треба буфер
- `insert` — у файлі зайві слова → зачепили сусідню фразу
- `replace` — слово почулось інакше → whisper недочув, різ правильний

Без цього розрізнення будь-яка недочутка whisper валила б правильно нарізаний кліп.

## Скоуп

Віддає **тільки сирі нарізані кліпи**. Заголовки, підзаголовки, чорні поля 9:16
і субтитри не пишуться і не рендеряться — це робота монтажера.

## Встановлення

```bash
mkdir -p ~/.claude/skills
cd ~/.claude/skills
git clone https://github.com/dpechenchis-design/max-clipping.git
```

Потрібні:

```bash
brew install ffmpeg
pip3 install faster-whisper
```

## Файли

```
max-clipping/
├── SKILL.md                   # визначення скіла: правила відбору + пайплайн
├── reference/
│   └── examples.md            # доказова база — розбір 9 готових кліпів клієнта
└── scripts/
    ├── parse_transcript.py    # читає txt / srt / vtt / «Спікер (00:12:04):»
    ├── validate_plan.py       # ФАЗА 1: цитати справді є в транскрипті
    ├── transcribe_source.py   # ФАЗА 2: пословний транскрипт відео
    ├── snap_clips.py          # ФАЗА 2: різи по межах слів
    ├── cut_clips.py           # ФАЗА 2: нарізка + склейка
    ├── verify_clips.py        # ФАЗА 2: перевірка готових файлів
    ├── analyze_examples.py    # розбір нових прикладів від клієнта
    └── textmatch.py           # спільне зіставлення тексту
```

Правила відбору у `SKILL.md` виведені з машинного розбору дев'яти готових
кліпів клієнта, а не вигадані — див. `reference/examples.md`. Імена гостей
знеособлені.
